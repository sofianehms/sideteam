# Changelog

## 0.2.0

* Retry failed checks and fall back to other configured engines.
* Record completed delegations, applications, and discards in a local journal.
* Show per-engine results, durations, reported tokens, and applications with `/sideteam:stats`.

## 0.1.0

* Add marketplace installation and guided engine setup.
* Delegate small coding tasks to Codex CLI, OpenCode, Gemini CLI, or custom executables in separate Git worktrees.
* Run project checks and return a compact summary for review before applying or discarding changes.
* Include local Ollama presets and a standalone server bundle.
* Document configuration, engine support, and security limits. Gemini CLI has not yet been verified in real conditions.
